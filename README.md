## 📱 About the Project

**MoneyTrack** is a Flutter-based personal finance tracking application focused on modern **UI/UX design**, simplicity, and ease of use.

The application allows users to view their financial overview, add transactions, monitor their balance, and manage their profile through a clean mobile interface.

> 🚫 No API Key required
> 🚫 No backend required
> 🚫 No Firebase required
> ✅ Local dummy data
> ✅ Flutter UI/UX focused

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or physical device

### Clone the Repository

```bash
git clone https://github.com/mulkiisse/Flutter.git
```

### Open the Project

```bash
cd Flutter
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```
